⚠ Compatibilidad de Sistema y Fuentes:
Los caracteres se representan según las fuentes instaladas en tu sistema operativo (Windows 10/11, macOS, Linux, ChromeOS).
Si algunos caracteres poco comunes (como CJK, Tibetano o Rúnico) se muestran como cuadros vacíos, puedes descargar estas fuentes gratuitas:

• Google Noto Fonts http://fonts.google.com/noto
• BabelStone Fonts http://www.babelstone.co.uk/Fonts/
• Quivira http://www.quivira-font.com/
• DejaVu Fonts http://dejavu-fonts.org/
